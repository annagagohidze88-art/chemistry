# ქიმიურ ელემენტთა პერიოდული სისტემა (React + TypeScript + Vite)

თანამედროვე, ქართულენოვანი საგანმანათლებლო ვებსაიტი და ინტერაქტიული ქიმიური ლაბორატორია.

### 📐 ორივე ტიპის პერიოდული სისტემა:
1. **კლასიკური მოკლეპერიოდიანი ფორმა (ნაგულისხმევი / სასკოლო ფორმა):**
   - **ჯგუფები რომაული ციფრებით ზემოთ:** **I, II, III, IV, V, VI, VII, VIII**.
   - **პერიოდები მარცხნივ:** **1, 2, 3, 4, 5, 6, 7** (დიდი პერიოდები 4, 5, 6, 7 დაყოფილია ზედა და ქვედა რიგებად).
   - **VIII ჯგუფის ტრიადები:** Fe-Co-Ni, Ru-Rh-Pd, Os-Ir-Pt, Hs-Mt-Ds.
   - **I პერიოდში (H) მეორე მდებარეობით VII ჯგუფში.**
   - **ელემენტების გაფერადება ბლოკების მიხედვით (ზუსტად სახელმძღვანელოს სქემის მიხედვით):**
     - 🟥 **s-ელემენტები** (წითელი)
     - 🟦 **d-ელემენტები** (ლურჯი)
     - 🟧 **p-ელემენტები** (ნარინჯისფერი)
     - 🟪 **f-ელემენტები** (შავი / იისფერი)
   - უჯრის განლაგება: ზედა მარცხენა კუთხეში — ქიმიური სიმბოლო, ზედა მარჯვენა კუთხეში — ატომური ნომერი, ქვემოთ — ქართული სახელი.
   - გამოყოფილი ლანთანოიდები (\*) და აქტინოიდები (\*\*).
2. **IUPAC 18-სვეტიანი გრძელი ფორმა:**
   - ერთი დაწკაპუნებით გადართვადი თანამედროვე საერთაშორისო ხედი.

### 🔬 ინტერაქტიული ლაბორატორია და 3D ატომური სიმულატორი:
- **⚛️ 3D ატომური ლაბორატორია (Atom Builder 3D - WebGL / Three.js):**
  - **3D ბირთვი (Nucleus):** პროტონებისა და ნეიტრონების 3D სფერული გროვა ნუკლონური მიკროვიბრაციითა და გაშლის (Expansion) კონტროლით.
  - **3D ელექტრონული ორბიტები და შრეები:** ბორ-ზომერფელდის გიროსკოპული 3D ორბიტები მანათობელი ელექტრონებით (K, L, M, N, O, P, Q).
  - **3D კვანტური ორბიტალების ღრუბელი:** s-ორბიტალის სფეროები, p-ორბიტალების განტელები ($p_x, p_y, p_z$), და d-ორბიტალების 3D ფორმები.
  - **ნაწილაკების ინტერაქტიული მართვა:** პროტონების ($p^+$), ნეიტრონების ($n^0$) და ელექტრონების ($e^-$) რეალურ დროში რეგულირება (მაუსით, სლაიდერით ან P/N/E კლავიშებით).
  - **სტაბილურობის ველი (Valley of Stability):** 2D ინტერაქტიული გრაფიკი $N$ vs $Z$ სტაბილური ნუკლიდების ზოლით, დაშლის ტიპების შეფასებით ($\beta^-$, $\beta^+$, $\alpha$, სპონტანური დაყოფა) და ნახევრადდაშლის პერიოდის მინიშნებებით.
  - **იონური მუხტი & იზოტოპის აღნიშვნა:** ნეიტრალური ატომი, კატიონი ($+q$) ან ანიონი ($-q$), მასური რიცხვი $A = Z + N$.
  - **ელექტრონული კონფიგურაცია:** აუფბაუს წესით $1s^2 2s^2 2p^6...$ და $2n^2$ შრეების შევსების ინდიკატორი.
  - **სწრაფი ნიმუშები (Presets):** $^1\text{H}$, დეიტერიუმი, $\alpha$-ნაწილაკი, $^{14}\text{C}$, $\text{Na}^+$, $\text{Cl}^-$, $^{56}\text{Fe}$, $^{197}\text{Au}$, $^{235}\text{U}$, $^{294}\text{Og}$.
  - **ქიმიური ვიქტორინა (Challenge Mode):** 8+ ინტერაქტიული ამოცანა საგანმანათლებლო ფაქტებით, ქულებითა და სერიით.
- **რეალური ფოტოსურათები:** თითოეულ ელემენტს თან ახლავს მისი ნამდვილი მაღალი ხარისხის ფოტოსურათი (Wikimedia Commons / IUPAC).
- **ბორის ატომური მოდელი:** SVG ანიმირებული ორბიტებითა და ელექტრონული შრეებით.
- **მრავალკომპონენტიანი ნაერთების შერევა:** შესაძლებელია 2, 3, 4 ან მეტი ელემენტის შერევა.
- **დეტალური ქიმიური შედეგები:**
  - ⬇️ **ნალექი (Precipitate):** ფერისა და ფორმის აღწერით (მაგ. $AgCl \downarrow$, $PbI_2 \downarrow$, $BaSO_4 \downarrow$, $CaCO_3 \downarrow$).
  - ⬆️ **გაზი / აირი (Gas release):** აირის გამოყოფის ჩვენებით ($CO_2 \uparrow$, $NO_2 \uparrow$, $SO_2 \uparrow$, $H_2S \uparrow$, $NH_3 \uparrow$).
  - ⚠️ **მარილარწარმომქმნელი (ინდიფერენტული) ოქსიდი:** მკაფიო განმარტებით ($CO$, $NO$, $N_2O$).
  - 🚫 **თუ ნაერთი არ წარმოიქმნება:** დიდი წითელი გაფრთხილება სამეცნიერო დასაბუთებითა და რეკომენდაციებით.
